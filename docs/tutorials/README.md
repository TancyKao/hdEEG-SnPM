# Tutorials

*Learning-oriented.* These take you by the hand through a first, working analysis so you build
confidence in the tool before you point it at your own data. They are lessons, not recipes: if
you already know what you want to do, go to the [how-to guides](../how-to/README.md); for exact
inputs and outputs, go to the [reference](../reference/ANALYSIS_CATALOG.md).

## Lessons

- **[Getting started: your first SnPM analysis](getting-started.md)** — run a complete hd-EEG
  group analysis in the GUI on the toolbox's own synthetic data, which has a 17-channel cluster
  planted in it, and watch the permutation test recover it. No statistics background and no
  data of your own required.

Everything you need is generated by `gen_synthetic_testdata` from the repo root — `test_data/`
is not in the repository.
